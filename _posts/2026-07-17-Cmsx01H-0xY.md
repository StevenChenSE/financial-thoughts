## Strix Point Power in a Compact Form Factor

The GeekCom A9 Max brings the AMD Strix Point architecture to the mini PC market at a competitive price point under $1,000. Powered by the Ryzen AI 9 HX370 processor, this machine features a flexible memory controller built on a 4nm process. Unlike competitors with soldered RAM, the A9 Max supports upgradeable memory, allowing configurations up to 128 GB. This review examines its capabilities in developer workloads and local large language model inference.

## Design and Connectivity

The A9 Max features a refined chassis with extensive port selection. The front panel includes an SD card reader, four USB-A ports, a headphone jack, a power button, and a Kensington lock. The rear connectivity is robust, offering two 2.5 GbE ports (linkable to 5 GbE), two USB4 ports, two HDMI ports, two additional USB-A ports, and the power input. Power efficiency is notable, with idle consumption measured at just 3.7 watts.

## Synthetic Benchmarks

In synthetic testing, the A9 Max performs competitively against other mini PCs. Geekbench scores reached 2891 for single-core and 13,922 for multi-core performance. While the Beink S1 achieved slightly higher scores, the A9 Max remains strong in its class.

Web performance is a highlight. In Speedometer 3.1, the system scored 37.4, a result that trails only the Mac Mini M4 and M4 Pro. This indicates excellent single-core efficiency for browser-based tasks. However, the Web Tooling Benchmark yielded a TypeScript score of 19.68 runs per second, which lags behind the Mac Mini M4/Pro and the discontinued Snapdragon X Elite dev kit, though it matches the Beink S1.

## Developer Workloads

Real-world development testing reveals the system's practical utility. Using an Nx monorepo with React and Next.js containing approximately 26,000 components, the build time was measured at 14.2 seconds after clearing the cache. This performance aligns with the Beink S1 and demonstrates viable productivity for modern web development stacks.

Multi-core capability was tested with a Python Mandelbrot algorithm. The 12-core, 24-thread processor completed the task in 33.29 seconds, drawing approximately 75 to 80 watts under load. This result approaches the performance of the Mac Mini M4. .NET builds, including a massive project generating 100,000 namespaces, completed in 95.66 seconds, offering solid performance for the price segment.

## LLM Inference and RAM Upgradability

The Ryzen AI 9 HX370 includes an integrated Radeon 890M GPU with 4.5 GB of dedicated VRAM. Local LLM testing was conducted using LM Studio with Vulkan acceleration.

With the base configuration, the OpenAI GPT-OSS 20B mixture-of-experts (MoE) model achieved 13 tokens per second with partial GPU offloading. By optimizing layer offloading, the model ran entirely on the GPU, reaching 20.25 tokens per second. The MoE architecture allowed the model to fit within the GPU memory despite its size.

To test larger models, the system was upgraded with a 96 GB DDR5-6000 RAM kit. This enabled the loading of the Llama 3.3 70B dense model. With 47 of 80 layers offloaded to the GPU via shared memory, the model generated text at 1.63 tokens per second. While slow, this confirms the feasibility of running 70B parameter models on the platform.

The GPT-OSS 120B MoE model also ran on the upgraded configuration. With 26 layers offloaded, the system achieved 11.44 tokens per second, utilizing 77% GPU and 84% CPU resources. Attempts to offload more layers resulted in load failures, indicating the limits of the GPU's memory bandwidth and capacity.

## Summary

The GeekCom A9 Max offers a compelling value proposition for developers and AI enthusiasts. The Ryzen AI 9 HX370 provides strong single-core performance and capable multi-core throughput, all within a sub-$1,000 price bracket. The upgradeable memory design is a significant advantage, enabling the use of large local LLMs that are inaccessible on systems with soldered RAM. While it does not match the peak performance of high-end Mac Mini configurations, the A9 Max delivers a balanced feature set, extensive connectivity, and sufficient power for demanding dev workloads and experimental AI inference.
